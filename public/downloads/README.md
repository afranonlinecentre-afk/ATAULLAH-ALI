This directory serves the signed Android APK binaries for AFRAN ONLINE CENTRE:

1. Customer App:
   File path: /public/downloads/afran-customer-app-v1.0.2.apk
   Public URL: /downloads/afran-customer-app-v1.0.2.apk

2. Owner Admin App (Restricted to Owner):
   File path: /public/downloads/afran-owner-admin-v1.0.1.apk
   Public URL: /downloads/afran-owner-admin-v1.0.1.apk

When a signed APK is placed here, the web download page automatically detects the file via HTTP HEAD and initiates instant binary download for citizens and verified owners.
